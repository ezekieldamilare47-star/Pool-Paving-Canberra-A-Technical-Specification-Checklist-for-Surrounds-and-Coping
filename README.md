|---|---|

## Stage 5: Plan for Repairs

| Trigger | Intervention |
|---|---|
| Loose, broken or missing pavers | Replace or re-bed |
| Level change > 15mm between pavers | Replace or re-bed |
| Sinking pavers causing pooling | Re-level, replace or re-bed |
| Slippery pavers (oil or moss) | Pressure wash, replace or re-bed |
| Water pooling | Channel drain or pit box |
| Tree root damage | Cut roots, replace segment |

| Root Cause | Prevention |
